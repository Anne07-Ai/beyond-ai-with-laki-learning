# Beyond AI with Laki — Learning Library

Standalone static learning site for the **30 Days of LLMs** educational series.

## Deployment
- Host: Cloudflare Pages (static assets)
- Git branch for preview: `feat/learning-library-v1`
- Build command: **leave empty**
- Build output directory: **/** (repository root)
- Root directory: **/**

## Routes
- `/` — Learning Library home
- `/day/1/` — Day 1 notes, examples, quiz, further reading
- `/styles.css` — Responsive brand styling

The Day 1 page uses the browser's native **Print / Save as PDF** control for download. A separately reviewed, original PDF from the AI Studio can be added later at `/notes/day01.pdf` without misleading dead download links.

## Safety and governance
- No tracking, collection of email addresses, external scripts, API keys, or payments.
- Repository is public; never commit private source assets or account credentials.
- Lesson pages require human fact-check and editorial review before live public rollout.
- Only publish approved episode notes.
- Do not imply Instagram auto-DM is enabled until Manychat delivery is tested.

## Brand
Elegant pink and lavender, technical clarity, human-friendly teaching. Maintain a separate deployment from the personal portfolio and from the local content-generation studio.
